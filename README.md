# Pinger Time Management
Приложение для регулярных напоминаний, которое упрощает концентрацию внимания. На текущий момент поддерживается только для Linux на Wayland.

## Интерфейс
В соответствии с расписанием возникает окно с напоминанием и двумя кнопками — «Делаю» и «Закрыть». Первая кнопка помечает дело как начатое, вторая сдвигает начало на минуту после нажатия кнопки.

## Конфигурация
Расписание задается в файле `$HOME/.config/pinger.conf`. Каждая строчка — это какое-то дело (допускаются пустые строчки), дело описывается названием с дополнением:
- `$`начало (по умолчанию 00:00)
- `~`длительность (по умолчанию 20 минут)
- `@`идентификатор (по умолчанию присваивается по времени начала)

Любое время или промежуток времени следует записывать либо количеством минут, либо ЧЧ:ММ. Идентификатор используется для того, чтобы различать изменение дела (идентификатор не изменился) от создания новых (новый идентификатор), по нему хранится статус начато или нет.

### Пример
```
$10:20 Идти на завтрак
$10:50 ~5:0 Работать @work
$15:00 Обед!!
```

## В будущих версиях
- произвольные время для повторного напоминания
- в случайные моменты напоминания в процессе с подсчетом количества пропусков
- сдвиг расписания, если предыдущее дело пересекается со следующим
- специальное окно для редактирования расписания
- поддержка Windows, X11 на Linux и MacOS
